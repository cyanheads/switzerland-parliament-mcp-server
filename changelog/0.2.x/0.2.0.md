# 0.2.0 — 2026-11-15

## Added

- **`skill://switzerland-parliament-guide/SKILL.md`** is a published skill covering identifier routes, picking the right roll call, and the checks before reporting votes, speakers, and committee membership. Served through `createApp({ skills: 'skills' })` and shipped in the npm package, the `.mcpb` bundle, and the Docker image.
- **`chparl_search_members`** takes `committeeId` to list a committee's current members, one row per membership with its function. Outputs add `committeeFound` and `guidance` (an unknown committee, versus an empty roster); `membership` `former` or `all` fails as `incompatible_fields`. [#9](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/9)
- **`chparl_search_transcripts`** adds page-level `subjectBusinesses`, mapping each delivered passage's `subjectId` to the businesses published for that debate. Best-effort: on an upstream failure the field is omitted with a notice. [#7](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/7)

## Changed

- **`chparl_get_business`** advertises a row schema per relationship array (`statusHistory`, `bills`, `relatedBusiness`, `preconsultations`, `subjects`), shrinking `tools/list`; emitted values are unchanged. [#10](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/10)

## Fixed

- **`request_too_long`**: a text filter whose URL-encoded request exceeds the source's 2,048-byte query-string limit is refused before any request, declared on `chparl_search_business`, `chparl_search_members`, and `chparl_search_transcripts`; 0.1.2 surfaced it as an opaque `-32603 … HTTP 404`.
