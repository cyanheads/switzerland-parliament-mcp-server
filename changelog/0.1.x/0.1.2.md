# 0.1.2 — 2026-10-25

## Added

- **`chparl_get_votes`** pages member voting history by `personNumber`, optionally narrowed by business or session, and discovers roll calls directly by `sessionId`. History rows include published vote, business, session, and time context. [#6](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/6)
- **Decision count buckets** retain distinct verbatim source labels in `decisionTexts`, including unknown codes, for page, vote, and parliamentary-group totals. [#8](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/8)
- **Agent Plugins manifests** provide root `plugin.json` and `mcp.json` alongside the existing client overlays.

## Changed

- **Desktop bundles** exclude node-gyp intermediates and build-only dependency files; packaging validation checks the completed archive and plugin manifests.
- **Framework tooling and documentation** adopt published-skill validation, refreshed development guides, streamlined client setup, and hosted-endpoint discovery metadata.

## Fixed

- **Author searches** omit expensive whole-query counts and use one extra matching row to establish cursor continuation; `totalCount` is absent for these searches. [#4](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/4)
- **Member decision `cantonId`** uses canonical `CantonNumber`, while additive `votingCantonId` preserves the original Voting identifier. [#5](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/5)
- **Reversed date ranges** in business and transcript searches return declared `incompatible_fields` metadata with ascending-range recovery guidance. [#11](https://github.com/cyanheads/switzerland-parliament-mcp-server/issues/11)
